# 🛒 Customer Shopping Behavior Analysis

This project analyzes customer shopping patterns using **Python**, stores processed data in **MySQL**, and visualizes insights using **Power BI**.  
The goal is to understand purchase trends, customer demographics, product performance, and rating behaviors to support data-driven business decisions.

---

## 📂 Project Workflow

| Step | Tool | Description |
|------|------|-------------|
| 1 | Python (Pandas) | Data cleaning, preprocessing, outlier handling, feature creation |
| 2 | MySQL | Structured storage of cleaned dataset and execution of analytical queries |
| 3 | Power BI | Interactive dashboards and data visualization |

---

## 🧰 Technologies Used

- **Python 3.9+**
  - Pandas
- **MySQL 8.0**
- **Power BI**
- **Jupyter Notebook**

## 🔍 Key Analysis Performed

- Handling missing values and duplicates  
- Encoding categorical variables  
- Customer segmentation using quantiles (qcut)  
- Identifying purchasing patterns by:
  - **Gender**
  - **Age group**
  - **Shopping category**
- Top products based on average review rating  
- Seasonal/Monthly purchase trends  
- Price vs Review rating correlation

---

## 📊 Power BI Dashboard Highlights

- Sales breakdown by category  
- Customer demographic analysis  
- Average product review rating visualization  
- Top-selling products  
- Monthly purchase trends
